Road Roster Generator

Using local spatial road centerlines, this script generates an xlsx file providing an output of all features within the feature class.

Python ArcPy Pandas Data Manangement Road Centerlines

PROJECT OVERVIEW

Why this was necessary

Maintaining an accurate road roster is important for providing a consistent reference of recognized roadways within the locality. Previously, producing or updating this information could require manually reviewing road records, organizing attributes, and formatting the results into a usable document.

Automating the process reduces repetitive work, minimizes the potential for transcription or formatting errors, and helps ensure that the published roster remains consistent with the underlying GIS data.

WORKFLOW

How the script works

  1. Calculate roadway mileage & address ranges.
    The script adds a mileage field and calculates road length in miles. It also reviews the left- and right-side address ranges from the source data to determine the lowest and highest address values associated with each roadway.
  2. Build a tabular road roster.
    ArcPy cursors read the processed feature class and transfer the resulting attributes into a pandas DataFrame, allowing the GIS-derived information to be organized as a clean tabular dataset.
  3. Format & export the final Excel file.
    Unnecessary fields are removed, mileage values are rounded for readability, and the roster is exported to a date-stamped Excel workbook for distribution and reference.
  4. Clean up temporary GIS data.
    After the roster is successfully generated, the temporary dissolved feature class and map layer are removed so the workflow does not leave unnecessary processing data behind.

How the Road Roster Generator works

Selected portions of the workflow demonstrate how authoritative road centerlines are filtered, consolidated, analyzed, and converted into a formatted Excel road roster.

RoadRosterGenerator.py — Filter & Consolidate Roads 
filtered_layer = "e911roads_filtered"

          where_clause = """
          STREET NOT IN ('UNNAMED ST', 'XOVER')

          """

          arcpy.management.MakeFeatureLayer(

          )
01

Filter and consolidate the road network

The workflow first removes road records that should not appear in the final roster. Road segments sharing the same street name, route number, and road class are then dissolved together so the output represents each roadway as a consolidated record.

RoadRosterGenerator.py — Calculate Road Mileage 
arcpy.management.AddField(
              output_fc,
              "MILES",
              "DOUBLE"
          )

          arcpy.management.CalculateField(
              output_fc,
              "MILES",
              "!SHAPE.length@feet! / 5280",
              expression_type="PYTHON3"
          )
02

Calculate roadway mileage

A new mileage field is created for the consolidated roadway features. ArcPy calculates the spatial length of each road in feet and converts that measurement into miles for inclusion in the final roster.

RoadRosterGenerator.py — Determine Address Range 
low_high_dict = {}

          fields = [
              "STREET", "ROUTENUM", "CLASS",
              "LLO", "RLO", "LHI", "RHI"
          ]

          with arcpy.da.SearchCursor(
              filtered_layer,
              fields
          ) as cursor:

              for street, route, cls, llo, rlo, lhi, rhi in cursor:

                  key = (street, route, cls)

                  lows = [v for v in (llo, rlo) if v is not None]
                  highs = [v for v in (lhi, rhi) if v is not None]
03

Determine roadway address ranges

The source road centerlines contain left- and right-side low and high address values. The script groups those values by roadway and determines the overall minimum and maximum addresses associated with each consolidated road record.

RoadRosterGenerator.py — Build the DataFrame 
fields_for_df = [
              f.name for f in arcpy.ListFields(output_fc)
              if f.type not in ("OID", "Geometry")
          ]

          data = []

          with arcpy.da.SearchCursor(
              output_fc,
              fields_for_df
          ) as cursor:

              for row in cursor:
                  data.append(row)

          df = pd.DataFrame(
              data,
              columns=fields_for_df
          )
04

Convert GIS records into tabular data

Once the spatial processing is complete, the required attributes are read directly from the feature class and loaded into a pandas DataFrame. This provides a clean tabular structure that can be formatted for the final Excel deliverable.

RoadRosterGenerator.py — Export & Clean Up 
today_str = datetime.datetime.today().strftime("%Y%m%d")

          xlsx_filename = (
              "Local Road Roster - {0}.xlsx"
              .format(today_str)
          )

          xlsx_path = os.path.join(
              output_folder,
              xlsx_filename
          )

          df.to_excel(
              xlsx_path,
              index=False
          )

          arcpy.management.Delete(output_fc)
05

Generate the final Road Roster

The processed DataFrame is exported to a date-stamped Excel workbook, creating a repeatable final product for distribution and reference. Temporary processing data is then removed to keep the GIS workspace clean.
