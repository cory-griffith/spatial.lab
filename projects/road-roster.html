Road Roster Generator

Using local spatial road centerlines, this script generates an xlsx file providing an output of all features within the feature class.

Python ArcPy Pandas Data Manangement Road Centerlines

PROJECT OVERVIEW

Why this was necessary

Maintaining an accurate road roster is important for providing a consistent reference of recognized roadways within the locality. Previously, producing or updating this information could require manually reviewing road records, organizing attributes, and formatting the results into a usable document.
