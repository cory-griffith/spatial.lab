Official Zoning Map Book

Developed a Python workflow to refresh more than 300 ArcGIS Pro projects, access their active layouts, export the required map pages, and support generation of an official locality zoning map book.

Cartography Python Zoning

PROJECT OVERVIEW

Why this was necessary

The development of a color-coded digital zoning map book provides a quick and reliable reference for locating and understanding zoning throughout the locality. Organized by tax map number, the map book combines tax maps, inserts, zoning classifications, and historical plat research for isolated or unique areas into one accessible resource.

This resource supports both internal staff and external users by simplifying property research, improving access to zoning information, and reducing the time needed to locate and understand specific areas of interest.

WORKFLOW

How it happened.

  1. Research & Preparation.
    Research the existing tax map numbering system and historical records to identify and properly reference each area of interest.
  2. Develop a Standard Template.
    Create a standardized ArcGIS Pro (APRX) template and document formatting, symbology, naming, and layout standards for consistency across all map projects.
  3. Isolate Areas of Interest.
    Develop individual map projects based on each specific tax map, insert, or area of interest.
  4. Automate Map Exports.
    Use a developed Python script to automatically process and export the completed layouts into the final digital map book.
Design note:Maintain uniform project structure, symbology, naming conventions, and layout formatting throughout the workflow to ensure consistency and organization as the map book expands.

CODE WALKTHROUGH

How the Zoning Map Book export workflow works

The ArcPy workflow automates the repetitive process of opening multiple ArcGIS Pro projects and exporting their layouts into organized PDF directories. Selected portions of the script demonstrate how the project groups are configured, discovered, and processed.

ZoningBookAutoLayout.py — Configure Project Groups 
paths = [
            {
                "source": r"...\APRX Projects\APRX 1-10",
                "dest": r"...\Maps 1-10"
            },
            {
                "source": r"...\APRX Projects\APRX 11-19",
                "dest": r"...\Maps 11-19"
            },
            {
                "source": r"...\APRX Projects\APRX 20-29",
                "dest": r"...\Maps 20-29"
            }
        ]
01

Organize the Map Book workflow

The script begins with a collection of source and destination folder pairs. Each source directory contains a group of ArcGIS Pro projects, while its corresponding destination identifies where the finished zoning-map PDFs should be stored.

ZoningBookAutoLayout.py — Prepare Output Directories 
for path_info in paths:

            source_folder = path_info["source"]
            dest_folder = path_info["dest"]

            if not os.path.exists(dest_folder):
                os.makedirs(dest_folder)
02

Prepare each export location

Each configured project group is processed independently. Before any layouts are exported, Python verifies that the corresponding destination directory exists and automatically creates it when necessary.

ZoningBookAutoLayout.py — Discover ArcGIS Pro Projects 
for root, dirs, files in os.walk(source_folder):

            for file in files:

                if file.lower().endswith(".aprx"):

                    aprx_path = os.path.join(
                        root,
                        file
                    )

                    aprx = arcpy.mp.ArcGISProject(
                        aprx_path
                    )
03

Automatically locate each APRX

Rather than manually opening every zoning-map project, the script recursively searches each configured directory for ArcGIS Pro project files. When an APRX is found, ArcPy opens the project so its layouts can be accessed programmatically.

ZoningBookAutoLayout.py — Export Layouts to PDF 
for layout in aprx.listLayouts():

            pdf_name = layout.name + ".pdf"

            pdf_path = os.path.join(
                dest_folder,
                pdf_name
            )

            layout.exportToPDF(
                pdf_path,
                resolution=300
            )

        del aprx
04

Batch export the finished maps

ArcPy retrieves every layout contained within the project and automatically names the resulting PDF from the layout name. Each map is exported at 300 DPI to its assigned folder before the project is released and processing continues to the next APRX.
