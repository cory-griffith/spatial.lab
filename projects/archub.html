ArcGIS Hub

Utilizing an established ArcGIS Online account, I was able to develop a landing page housing all web applications for the public specific for one locality.

HTML CSS ArcGIS Online ArcGIS Hub

PROJECT OVERVIEW

Why this was necessary

ArcGIS Hub provided a more customizable and centralized approach for delivering public-facing GIS applications and information. Rather than requiring residents to navigate individual applications or disconnected links, the Hub creates a single, organized location where the public can access maps, applications, data, and other GIS resources.

Considering the locality and the variety of information provided to residents, ArcGIS Hub also allows the County to organize GIS content around specific community needs while maintaining consistent branding and navigation. This improves accessibility, simplifies the public user experience, and provides a platform that can expand as additional GIS applications and resources are developed.
