ArcGIS Online Public Parcel Viewer

Development of a public facing web applicaion through ESRI's ArcGIS Online platform.

ArcGIS Online Arcade Automation Web Experience Builder

PROJECT OVERVIEW

Why this was necessary

Due to IT security requirements and limited GIS infrastructure, hosting a public-facing parcel viewer internally was not practical. I developed a cloud-hosted solution using ArcGIS Online, eliminating reliance on a third-party consultant to host/manage, while providing a more cost-effective approach.

Bringing the application under GIS management gives the organization greater control over its public-facing data and allows updates to be published more quickly. This provides the public with a more current, reliable, and maintainable GIS resource.

MORE INFORMATION

Details

  1. ArcGIS Online Hosted
    Utilizies under 130 credits a month from storage.
  2. Scripting
    Developed a Python script to automatically pull specific layers from our database.
  3. Uploads
    Output of script is a GDB, which I manually overwrite the source layers in ArcGIS Online.
Design note: Once schema is established within AGOL, the GDBs must maintain this or uploads will not work. Also, ensure data within AGOL is non-editable.

RESULT

Outcome and next steps

The implementation of this application has provided the locality with greater control over its public-facing GIS while reducing budgetary pressure on the department. Application maintenance and data updates are now handled in-house. Future improvements will include additional parcel attributes and continued enhancements to the custom parcel pop-up experience.
